# AI FAQ Chatbot

An AI-powered FAQ chatbot that delivers natural, context-aware responses using Large Language Models (LLMs). Built to demonstrate practical LLM API integration, prompt engineering, and responsive front-end development.

![License](https://img.shields.io/badge/license-MIT-blue.svg)

## Overview

Traditional FAQ widgets rely on rigid keyword matching and rarely understand how users actually phrase questions. This project replaces that approach with an LLM-driven conversational interface that interprets intent, holds context across a conversation, and responds naturally — all wrapped in a clean, ChatGPT-inspired UI.

## Features

- **AI-powered conversational interface** — natural back-and-forth instead of static Q&A
- **Context-aware responses** — understands follow-up questions, not just isolated queries
- **LLM API integration** — connects directly to a Large Language Model for response generation
- **Prompt engineering** — structured prompts tuned for accurate, on-topic answers
- **ChatGPT-inspired UI** — familiar, intuitive chat experience
- **Responsive design** — works across desktop and mobile
- **Dark mode support** — built-in theme toggle

## Getting Started

### Prerequisites

- A modern web browser
- An API key from your LLM provider of choice

### Installation

```bash
git clone https://github.com/ShynCode/AI-FAQ-Chatbot.git
cd AI-FAQ-Chatbot
```

### Configuration

Add your LLM API key before running the app. Depending on how the project is set up, this is typically done in a config or `.env` file, e.g.:

```
API_KEY=your_llm_api_key_here
```

> ⚠️ Never commit your API key to version control. Add your config/`.env` file to `.gitignore`.

### Run

Open `index.html` in your browser. No build step required.
